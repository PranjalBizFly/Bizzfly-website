# Performance and Core Web Vitals

## Objective
Make the website fast, stable and efficient without removing required functionality.

## Core Metrics
Optimize:
- LCP
- INP
- CLS
- TTFB
- FCP

## Assets
Optimize:
- Images
- Fonts
- CSS
- JavaScript
- SVG
- Third party scripts

Use responsive images, modern formats, lazy loading and appropriate caching.

## Code
Use:
- Code splitting
- Tree shaking
- Minification
- Deferred non critical scripts
- Critical resource prioritization
- Removal of unused code

## Network
Use caching, compression and CDN where appropriate.

## Mobile
Test performance on realistic mobile conditions, not only high end desktop hardware.

## Rules
Do not sacrifice accessibility, security or functionality solely for a performance score.

## Deliverable
Report major performance bottlenecks, fixes and before/after measurements where tools are available.
