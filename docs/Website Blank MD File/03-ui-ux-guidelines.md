# UI UX Guidelines

## Objective
Deliver a clear, usable and consistent experience across desktop, tablet and mobile.

## User Experience
Optimize:
- User journeys
- Navigation
- Information hierarchy
- CTA placement
- Forms
- Search
- Checkout
- Account flows
- Error recovery
- Confirmation flows

## Interaction States
Every interactive component should support:
- Default
- Hover
- Focus
- Active
- Disabled
- Loading
- Success
- Error

## System States
Provide:
- Skeleton/loading state
- Empty state
- Error state
- Success state
- Confirmation dialog
- Friendly validation message

## Mobile UX
Ensure:
- Touch friendly controls
- No horizontal overflow
- Readable text
- Accessible menus
- Proper keyboard behavior
- Easy form completion

## Rules
Do not add unnecessary popups, animations or friction. Do not redesign working sections without a clear UX reason. Prefer reusable components.
