# Accessibility Standards

## Objective
Build an inclusive website that is usable with keyboards, assistive technologies and different interaction methods.

## Semantic HTML
Use correct:
- Headings
- Landmarks
- Buttons
- Links
- Forms
- Lists
- Tables

## Keyboard
Ensure:
- Logical tab order
- Visible focus
- Keyboard accessible menus
- Keyboard accessible dialogs
- No keyboard traps

## Forms
Provide:
- Labels
- Instructions
- Clear validation
- Error association
- Accessible required state

## Images
Use meaningful ALT text where needed. Decorative images should not create unnecessary screen reader noise.

## Contrast
Maintain readable contrast for text and controls.

## Motion
Respect reduced motion preferences.

## Testing
Use automated accessibility checks plus manual keyboard and screen reader testing where practical.
