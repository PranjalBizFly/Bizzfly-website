# Structured Data and Schema

## Objective

Implement accurate Schema.org structured data that reflects actual website content.

## Potential Types

Use only where applicable:

[ ] Organization  
[ ] LocalBusiness  
[ ] WebSite  
[ ] WebPage  
[ ] Service  
[ ] Product  
[ ] Article  
[ ] BreadcrumbList  
[ ] FAQPage where genuine  
[ ] Person  
[ ] Event  
[ ] Review where legitimately supported  

## Rules

Schema must match visible content.

Never create:

- Fake reviews
- Fake ratings
- Fake FAQs
- Fake prices
- Fake locations
- False certifications

## Implementation

Prefer valid JSON LD where appropriate.

Avoid duplicate or conflicting schema.

## Validation

Test structured data after implementation and fix syntax, property and consistency errors.

## Maintenance

Update schema whenever the underlying business information changes.
