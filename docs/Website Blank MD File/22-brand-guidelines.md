# Brand Guidelines and Design Consistency

## Objective
Make every part of the website look like one unified brand.

## Audit
Identify:
- Brand name
- Logo and variants
- Brand colors
- Typography
- Buttons
- Radius
- Shadows
- Icons
- Imagery
- Spacing
- Navigation
- Footer
- Visual language

## Logo
Preserve proportions, colors and approved variations. Do not stretch, distort, recolor or add arbitrary effects.

## Colors
Create centralized tokens for primary, secondary, accent, backgrounds, surfaces, text, borders and functional states. Do not invent colors when an established palette exists.

## Typography
Follow the separate typography rules and do not introduce unrelated fonts.

## Components
Standardize buttons, forms, cards, inputs, navigation, modals, alerts, badges and other reusable components.

## Spacing
Use a consistent spacing system and existing website values where established.

## Radius and Shadows
Maintain consistent border radius and restrained shadows.

## Icons and Images
Use consistent icon family, stroke style, image ratios, cropping and visual treatment.

## Responsive Design
Preserve brand identity across desktop, tablet and mobile.

## Dark Mode
Create a proper brand compatible dark theme. Check logo, contrast, text and functional colors.

## Motion
Use restrained, consistent animations and respect reduced motion preferences.

## Third Party Components
Integrate maps, payments, authentication and other third party interfaces so they visually fit the website where customization is supported.

## Final Rule
Do not redesign the brand while implementing functionality. Existing brand identity is the source of truth.
