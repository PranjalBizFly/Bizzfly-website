# Search and Discovery

## Objective

Provide fast and useful content discovery for websites that require search.

## Features

[ ] Global search  
[ ] Search suggestions  
[ ] Search results  
[ ] Filters  
[ ] Sorting  
[ ] Categories  
[ ] Pagination  
[ ] No results state  
[ ] Typo handling  

## SEO

Prevent uncontrolled search result URLs from becoming indexable.

Use clean URLs and appropriate canonical and indexing rules.

## Analytics

Where analytics is enabled, track:

[ ] Search terms  
[ ] No result searches  
[ ] Filter usage  
[ ] Result clicks  

Respect applicable privacy requirements.

## Performance

Use efficient queries, pagination and caching where appropriate.

## Accessibility

Search must be keyboard accessible and have proper labels and focus behavior.
