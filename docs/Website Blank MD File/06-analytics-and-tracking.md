# Analytics and Tracking

## Objective
Implement measurable business events without duplicating tracking or collecting unnecessary data.

## Core Tracking
Where applicable configure:
- Google Analytics 4
- Google Tag Manager
- Google Search Console
- Microsoft Clarity
- Meta Pixel
- LinkedIn Insight Tag

## Events
Consider:
- CTA click
- Phone click
- WhatsApp click
- Form start
- Form submission
- Form error
- Login
- Registration
- Search
- Download
- Appointment booking
- Checkout start
- Payment success
- Payment failure

## Rules
Use meaningful event names and parameters. Avoid duplicate page views and duplicate conversion events.

Respect applicable privacy and consent requirements.

## Validation
Test events using the relevant platform debugging tools and document event names and triggers.
