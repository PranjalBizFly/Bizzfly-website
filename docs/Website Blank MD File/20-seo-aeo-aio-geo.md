# SEO AEO AIO GEO Optimization

## Objective
Optimize the existing website for traditional search, answer engines and AI generated search without changing approved business content.

## Content Preservation
Do not rewrite, remove or replace existing business content, pricing, claims, services, headings or messaging. Optimize presentation and technical signals instead.

## SEO
Audit and optimize:
- Title tags
- Meta descriptions
- Heading hierarchy
- URLs
- Canonicals
- Internal links
- Image ALT text
- Open Graph
- Robots.txt
- XML sitemap
- Redirects
- Crawlability
- Indexability
- Structured data

## Keyword Optimization
Identify primary, secondary, long tail, commercial, informational, local and question based keywords. Use them naturally in metadata, structure, links and image attributes. Avoid keyword stuffing.

## Technical SEO
Check HTTPS, status codes, rendering, JavaScript, CSS, duplicate URLs, redirects, sitemap and robots configuration.

## Schema
Use valid Schema.org types only when supported by actual content, such as Organization, LocalBusiness, WebSite, WebPage, Service, Product, BreadcrumbList, Article, FAQPage where genuine and ContactPage.

Never create fake reviews, ratings, FAQs, prices, locations or claims.

## AEO
Improve semantic HTML, question intent signals, structured data, entity relationships and clear existing answers.

## AIO
Make company, services, industries, locations and relationships machine understandable through semantic structure, metadata and schema.

## GEO
Strengthen entity clarity, service relevance, topical relevance, trust signals, structured data and internal relationships.

## Local SEO
Where applicable maintain consistent name, address, phone, hours, location and LocalBusiness schema. Never create fake locations.

## Mobile and Performance
Optimize responsive behavior and Core Web Vitals including LCP, INP and CLS.

## Final Report
Report pages analyzed, issues found, changes made, schema, keyword work, AEO/AIO/GEO work, mobile and performance improvements, remaining issues and realistic next steps. Never guarantee rankings.
