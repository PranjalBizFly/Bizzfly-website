# Website Page Structure and Information Architecture

## Objective
Create a clear, scalable website architecture without unnecessarily changing the existing structure.

## Required Audit
Map:
- Homepage
- Service pages
- Product pages
- About
- Contact
- Blog and content pages
- Location pages
- Login and account pages
- Checkout and payment pages
- Policy pages
- Error pages
- Admin pages where applicable

## Rules
Use logical URL structures, consistent navigation and reusable page templates. Preserve existing URLs whenever possible. If a URL must change, use a proper 301 redirect.

## Navigation
Define:
- Primary navigation
- Secondary navigation
- Mobile navigation
- Breadcrumbs
- Footer navigation
- Contextual internal links

## Page States
Plan:
- Loading
- Empty
- Error
- Success
- Unauthorized
- Not found
- Maintenance

## Deliverable
Provide a sitemap, page hierarchy, URL map and reusable template strategy before major structural changes.
