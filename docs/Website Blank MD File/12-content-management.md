# Content Management

## Objective
Keep website content maintainable without allowing uncontrolled changes to approved business messaging.

## Content Types
Where required support:
- Pages
- Services
- Products
- Blog posts
- Categories
- FAQs
- Testimonials
- Team
- Locations
- Media

## Workflow
Use:
- Draft
- Review
- Publish
- Update
- Archive

## Content Rules
Preserve approved business claims, pricing and messaging unless explicitly changed by an authorized user.

## SEO
Dynamic content should support:
- Title
- Meta description
- Canonical
- Open Graph
- Schema where appropriate

## Media
Validate file type, size and dimensions. Store media securely and optimize delivery.

## Permissions
Only authorized roles should create, edit, publish or delete content.
