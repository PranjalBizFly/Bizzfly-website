# Database and API Architecture

## Objective
Create maintainable, secure and scalable data and API foundations.

## Database
Define:
- Entities
- Relationships
- Primary keys
- Foreign keys where applicable
- Constraints
- Indexes
- Audit fields
- Soft delete strategy where needed

## API
Use consistent:
- Routes
- HTTP methods
- Authentication
- Authorization
- Validation
- Pagination
- Filtering
- Sorting
- Error responses
- Status codes

## Security
Validate all input server side. Enforce authorization at the API layer. Never trust client supplied roles or ownership information.

## Reliability
Support:
- Timeouts
- Retry strategy where safe
- Idempotency for payment or critical operations
- Transaction handling
- Logging
- Monitoring

## Documentation
Document API endpoints, request fields, responses, authentication and errors.
