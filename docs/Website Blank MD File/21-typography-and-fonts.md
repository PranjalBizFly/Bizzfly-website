# Typography Fonts and Text Consistency

## Objective
Preserve the existing typography system while ensuring readability, responsiveness and performance.

## Audit
Identify:
- Primary and secondary fonts
- Heading and body fonts
- Font weights
- Sizes
- Line heights
- Letter spacing
- Text colors
- Link and placeholder colors

## Rules
Do not replace an established font without a clear reason. Do not rewrite existing business content.

## Font Performance
Use optimized formats such as WOFF2 where available. Load only required font families and weights. Avoid unnecessary variants.

## Hierarchy
Maintain logical H1 to H6 structure and consistent styles for body, labels, navigation, buttons, forms and footer.

## Responsive Typography
Ensure headings do not overflow, text remains readable, buttons fit and no layout causes horizontal scrolling.

## Readability
Maintain appropriate font size, line height, paragraph width, contrast and spacing.

## Dark Mode
Use a dedicated readable dark typography system rather than simply inverting colors.

## Components
New login, payment, forms, policies, popups, menus and other components must use the existing typography system.

## Accessibility
Maintain readable contrast, focus states, adequate interactive text size and keyboard usability.

## Validation
Check font consistency, loading, hierarchy, mobile behavior, dark mode, text overflow and preservation of existing content.
