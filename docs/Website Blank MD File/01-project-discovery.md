# Project Discovery and Requirements

## Objective
Understand the business, users, goals, constraints, technology and required integrations before changing the website.

## Mandatory Audit
Inspect:
- Business purpose and target audience
- Existing pages and user journeys
- Existing features and integrations
- Current technology stack
- Hosting and deployment setup
- Database and APIs where applicable
- Authentication and user roles
- Payment requirements
- Geographic markets, languages and currencies
- Existing SEO, analytics and tracking
- Existing brand and design system

## Requirements Classification
Separate requirements into:
- Business requirements
- Functional requirements
- Non functional requirements
- Technical requirements
- Security requirements
- SEO requirements
- Accessibility requirements
- Performance requirements
- Integration requirements

## Rules
Do not invent business requirements. Preserve working functionality. Identify ambiguities and dependencies before implementation. Reuse the existing stack unless a change is justified.

## Deliverable
Produce a concise discovery report with assumptions, risks, dependencies, affected pages and implementation priorities.
